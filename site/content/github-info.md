## What's new (October 2026)

Short, practical highlights. Each item notes its source.

### From the GitHub Changelog

Source: [GitHub Changelog](https://github.blog/changelog/)

- **Stacked pull requests are generally available (Oct 6).** Break big changes into a chain of small, reviewable PRs.
- **Copilot code review: API support and a new default effort level (Oct 2).** Automate reviews and expect different default depth.
- **Selected Copilot models deprecated (Oct 2).** Check your model pickers and settings.
- **Secret scanning adds detectors for Lovable, Supabase, and more (Oct 5).** More leaked credentials get caught automatically.
- **npm publishing hardening (Oct 2).** Staged publishing now supports new packages, and unvalidated trusted publishing configurations now expire.
- **Security advisories (Oct 1-2).** Structured forms, rate limits, and confidential comments for private vulnerability reports.

### From Awesome Copilot workflows

Source: [Awesome Copilot workflows](https://awesome-copilot.github.com/workflows/) (listing at [github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/workflows))

Ready-made agentic workflow examples to learn from:

- `daily-issues-report` – daily summary of repository issues.
- `ospo-contributors-report`, `ospo-org-health`, `ospo-stale-repos`, `ospo-release-compliance-checker` – open source program office reporting and health checks.
- `relevance-check` and `relevance-summary` – triage content for relevance.
- `weekly-comment-sync` – recurring comment synchronization.
